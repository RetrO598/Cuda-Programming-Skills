# cuda-extended-lambda-restrictions

Minimal Codex Skill containing only the rules from NVIDIA CUDA Programming Guide
**5.3.8.4 Extended Lambda Restrictions**.

## Install

```bash
mkdir -p ~/.agents/skills
cp -R cuda-extended-lambda-restrictions ~/.agents/skills/
```

Expected path:

```text
~/.agents/skills/cuda-extended-lambda-restrictions/SKILL.md
```

Restart Codex if the Skill is not discovered immediately.

## Example

```text
$cuda-extended-lambda-restrictions
Check this CUDA/Kokkos code only for CUDA extended-lambda restrictions.
```
